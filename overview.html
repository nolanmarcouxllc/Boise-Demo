The system catches it. The person decides it.

Every test run ends the same way — with a name and a question. Not one of these forty sends a truck, changes an order, or calls a customer on its own.

What this is. A working concept built on made-up orders, customers and routes. The test runs replay a sample day so you can see the shape of the work — they are not connected to Boise Cascade's real systems, and none of the numbers describe the real Westfield branch. The next step is a working session with operations and IT to find out which of these are worth building, and which are wrong.
